Open-source clipper for Hermes Agent. A file or YouTube URL becomes captioned 9:16 shorts. Whisper and FFmpeg run locally. Nothing is posted for you. 

$ python3 -m venv .venv && .venv/bin/pip install -e .

How it works

How it works

#1

In

Local file or public URL. yt-dlp when it is a link.

#2

Hear

faster-whisper on your machine. No cloud speech-to-text required.

#3

Choose

Heuristic planner. Optional Grok if you set XAI_API_KEY.

#4

Out

Tight 9:16. Word captions. Styles: pop, impact, clean.

Built for Hermes

What you get

  • CLI on Linux, plus a Hermes Agent plugin.
  • Use it from the Hermes session you already have.
  • Source and transcript stay on disk.
  • Writes files. Does not publish to socials.

What it is not

  • Not a signed macOS Electron clipper.
  • Not a cloud render bill.
  • Not auto-post.
  • Needs FFmpeg with libass and Python 3.11+.
