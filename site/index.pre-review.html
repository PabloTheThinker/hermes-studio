Wall FIG.02 — HONEST

Linux first. Local files.

What you get

  • CLI on Linux, plus a Hermes Agent plugin.
  • Talk to the agent in your usual Hermes chat. No extra sidebar app.
  • Transcription stays on your machine. The source file stays yours.
  • Exports files. It does not publish to socials.

What it is not

  • Not a signed macOS Electron clipper.
  • Not an OpenRouter transcription bill.
  • Not nine caption skins and auto-post.
  • Not a cloud render farm. FFmpeg runs here.
Command FIG.03 — RUN

Run.

cli 
python3 -m venv .venv && .venv/bin/pip install -e .
.venv/bin/python -m hermesclip run VIDEO.mp4 \
  --out ./clips --max-clips 3 \
  --pacing tight --style pop

In Hermes Agent, enable the hermesclip plugin and use hermesclip_run after a new session. Requires FFmpeg with libass and Python 3.11+.
