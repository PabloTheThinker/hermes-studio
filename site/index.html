The tools.

Pick one job, not a wall of settings. Each tool opens with the right defaults and only the options that matter for it.

01ClipsFind the moments.Scores hook, flow and value, names each clip, then cuts 3 to 8 shorts with captions, the right framing and a hook title.3–8 shorts
02CaptionsCaption the whole take.Word-by-word captions on the full video, in six styles, with your keywords highlighted.1 video
03ReframeChange the shape.16:9 to vertical, portrait or square. Hermes picks the layout: speaker crop, facecam split, or the whole frame on a blur pad.1 video
04TightenCut the dead air.Removes ums, uhs and long pauses from word timings, so the take feels edited without an editor.1 video
05TranscriptGet the words.SRT and VTT for any editor, plus clean text for notes and posts. No render needed..srt · .vtt · .txt

Same video.
Right frame.

Hermes looks at each clip before it cuts. A speaker gets cropped to the face. A stream with a facecam gets split, face on top or bottom, so nobody loses their head.

Layout

Auto · Speaker · Split · Classic

Opus-style layouts. Face on top or bottom, band from 20 to 60%.

Look

Eight filters

Punch, warm, cool, cinematic, vintage, black and white, bright.

Captions

Six styles · four spots

Word-by-word highlight, your keywords in colour, fix any misheard word.

Edit after

Re-cut any clip

Move in and out, change the look, re-render. The old take waits in Dropped.

Three steps.

Open the desk on localhost, or tell your agent. Same tools either way.

01

Drop a source

A file, YouTube, Twitch, Kick, X or a live stream. Studio checks it first.

02

Pick a tool

Or let Hermes read the video and pick the tool, length and format for you.

03

Edit, then take

Change the layout, filter or in and out of any clip and re-render. Social copy on request. You post.

What Hermes can do with a clip

  • CutHook-first windows, filler and pauses removed
  • FrameSpeaker crop, facecam split, blur pad
  • CaptionWord timing, keywords, fixes, position
  • GradeEight colour filters, progress bar
  • SoundDenoise, loudness to -14 LUFS
  • NameAI titles from the clip's own words

What stays on your machine

Everything.

  • Transcriptionfaster-whisper, local
  • Cutting and captionsFFmpeg, local
  • Your videoYour Hermes folder
  • PostingNever. That's yours.

Install.

Python 3.11+ and FFmpeg. Works as a Hermes Agent plugin, an MCP server or plain CLI.

Plugin for Hermes Agent

# clone and install
git clone https://github.com/PabloTheThinker/hermes-studio
cd hermes-studio && pip install -e .
# open the desk
hermesclip studio

Or straight from the CLI

# five tools, one flag
hermesclip run talk.mp4 --mode clip
hermesclip run talk.mp4 --mode tighten
hermesclip run talk.mp4 --mode transcript
