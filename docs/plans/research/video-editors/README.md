# Video-editor research for the Hermes Studio Edit page

This was a research-only pass, done Oct 1, 2026 (ET). No code was changed.

**Start with:**
- `RECOMMENDATION.md`: one page
- `MASTER-FEATURE-MATRIX.md`: features × 14 editors + a Hermes column (must / v1 / later)
- `UI-UX-PATTERNS.md`: recurring patterns + the recommended Edit page layout and keyboard map

**Teardowns:**
- **Open source:** `kdenlive.md`, `shotcut.md`, `openshot.md`, `olive.md`, `losslesscut.md`, `opencut.md`, `flowblade.md`, `pitivi.md`, `blender-vse.md`
- **Commercial:** `davinci-resolve.md`, `final-cut-pro.md`, `capcut.md`, `premiere-pro.md`, `descript.md`
- **Agent-native reference (added 2026-10-01):** `montaj.md`. Montaj (montaj.ag, by By Crux) is an AI tool for short-form video and carousels: an MIT engine for outside agents plus a waitlisted Mac app. It is reference only and not part of the 14-editor matrix; it gets an addendum in the matrix and a pattern (P15) in UI-UX-PATTERNS.md. `screenshots/montaj/` holds 28 images: 1 from Pablo, 15 official, 12 of our captures of the site's HTML mock-ups.

**Screenshots:** `screenshots/<editor>/`, each with a `SOURCES.md`. There are 196 images: 50 our own captures and 146 official. All are real; nothing was generated. Premiere has no images because Adobe blocked downloads. Pitivi has no own capture because it didn't render under Xvfb.
