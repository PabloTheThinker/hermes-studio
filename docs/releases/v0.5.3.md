## v0.5.3 — license notices for the bundled FFmpeg and PyAV

This release carries the third-party notices and license texts that v0.5.0, v0.5.1 and v0.5.2 were missing.

- **FFmpeg.** The app ships BtbN's static FFmpeg `n9.0.2-17-g2a571b6068`, which is GPL-3.0-or-later. `NOTICE` now names the exact release and file and both checksums. It also links to the matching FFmpeg source commit and the build scripts.
- **PyAV.** faster-whisper uses PyAV 18.1.0, whose wheel bundles the FFmpeg 8.1.2 libraries plus x264 and x265. `NOTICE` now lists them, with their licenses and source.
- **OpenCV.** `NOTICE` also covers the FFmpeg libraries inside the opencv-python-headless wheel.
- **In the app.** `NOTICE`, `LICENSE` and the full GPL and LGPL texts are inside the app, in `resources/` and in `resources/engine/`.
- **Source files.** Each release now attaches its source as `hermes-studio-0.5.3-source.tar.gz`. It also attaches the FFmpeg source and BtbN build scripts that match the bundled `ffmpeg`.

**Also new since v0.5.2**
- Design: a Canva-style editor for people and agents, with adjust, blend modes, copy style and shortcuts.

**Install or update**

```bash
curl -fsSL https://raw.githubusercontent.com/PabloTheThinker/hermes-studio/main/scripts/install.sh | bash
```

```powershell
irm https://raw.githubusercontent.com/PabloTheThinker/hermes-studio/main/scripts/install.ps1 | iex
```

**Or download the installer yourself:** `Hermes-Studio-Setup-0.5.3.exe` (Windows) or `Hermes-Studio-0.5.3.AppImage` (Linux). Check either one against `SHA256SUMS.txt`.

It runs on your computer only. Nothing is uploaded or posted.
