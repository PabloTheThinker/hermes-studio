## v0.6.1 — the plugin is the chat tools, without a Desktop helper

This patch keeps the v0.6.0 editor and engine, and aligns the package, desktop app and Hermes Agent plugin at 0.6.1. The Desktop `/studio` view that called system `python3` for a frame helper is gone. Hermes installers ship a private Python and do not provision that helper, so that page could fail on a clean host.

### Plugin

- `hermes plugins install hermes-studio` ships the chat plugin: the fourteen `hermes_studio_*` tools and the `/studio` slash command (`clip`, `captions`, `reframe`, `tighten`, `transcribe`, `this`, `desk`).
- The Desktop sidebar Studio page and `frame.py` are removed. Nothing outside the plugin directory is required for the tools to register.
- Caption lines are still written by the calling Hermes agent, not by a separate speech model. The plugin does not post.

### Already in the app

The timeline editor, Clips pipeline and Design page from v0.6.0 are unchanged.

### Install or update

```bash
curl -fsSL https://raw.githubusercontent.com/PabloTheThinker/hermes-studio/main/scripts/install.sh | bash
```

```powershell
irm https://raw.githubusercontent.com/PabloTheThinker/hermes-studio/main/scripts/install.ps1 | iex
```

**Or download the installer yourself:** `Hermes-Studio-Setup-0.6.1.exe` (Windows) or `Hermes-Studio-0.6.1.AppImage` (Linux). Check either one against `SHA256SUMS.txt`.

Linux: `… | bash -s -- --version v0.6.1` pins this release; `--uninstall` removes the app and keeps your clips. It installs to `~/.local/share/hermes-studio` and needs no FUSE.

It runs on your computer only. Nothing is uploaded or posted.
