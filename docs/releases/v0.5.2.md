## v0.5.2 — install from GitHub in one line

**Linux**

```bash
curl -fsSL https://raw.githubusercontent.com/PabloTheThinker/hermes-studio/main/scripts/install.sh | bash
```

**Windows** (PowerShell)

```powershell
irm https://raw.githubusercontent.com/PabloTheThinker/hermes-studio/main/scripts/install.ps1 | iex
```

The installer downloads this release, checks it against `SHA256SUMS.txt`, and installs it for your user only. It needs no admin rights, no Python and no FFmpeg. On Linux it also needs no FUSE. Run the same line again to update.

**New**
- `hermes-studio app` opens the desktop app. `hermes-studio update` gets the newest release; `--check` only looks.
- The app now carries its own `hermes-studio` command, so the command line and your AI apps work straight after install.
- `hermes-studio mcp install claude` (or grok, codex, cursor, hermes) gives your AI app a fixed path that keeps working after updates.
- Releases are now built, tested on clean Linux and Windows machines, and published by GitHub itself. These are the exact files those tests passed.

**Or download the installer yourself:** `Hermes-Studio-Setup-0.5.2.exe` (Windows) or `Hermes-Studio-0.5.2.AppImage` (Linux: `chmod +x`, then open it). macOS is not supported yet.

It runs on your computer only. Nothing is uploaded or posted.
